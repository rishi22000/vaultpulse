# Security Policy

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Security is paramount for **VaultPulse**, as it handles confidential corporate pitch decks, deliverables, and client agreements.

If you discover a security vulnerability within VaultPulse:
1. Please **do NOT** open a public issue on GitHub.
2. Email full vulnerability details, proof-of-concept, and impact assessment to:
   **security@neelbyte.com** or contact **Neelbyte Websolution** directly.
3. We will acknowledge receipt within 24 hours and provide an estimated remediation timeline.
